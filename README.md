# Bloom — дипломное web-приложение цветочного магазина

Bloom — локальный модульный монолит на FastAPI для демонстрации дипломного проекта: витрина магазина, корзина, оформление заказов, админ-панель с аналитикой, графиками и экспортом CSV.

## Стек
- Python 3.12
- FastAPI + Jinja2 + Bootstrap 5 + vanilla JS
- SQLAlchemy 2.x + SQLite
- Alembic
- Pydantic
- Session-based auth
- Chart.js
- pytest
- logging

## Возможности
### Клиентская часть
- Главная, каталог, карточка товара, поиск/фильтрация
- Рекомендованные/акционные/популярные товары
- Корзина в сессии, промокоды
- Checkout, расчет доставки по зонам, подтверждение заказа
- Мои заказы (по телефону/email)
- Страницы «О магазине» и «Контакты»

### Админка
- Dashboard с KPI и графиками
- Управление заказами/назначение курьера
- Таблица товаров (быстрое включение/выключение)
- Настройки зон и слотов доставки
- Логи действий
- Экспорт заказов CSV
- Экспорт аналитики CSV

### Бизнес-логика
- Номер заказа вида `BLM-2026-0001`
- Проверка остатков/неактивных товаров
- Поддержка собираемых букетов (через ProductComponent)
- Имитация платежей (`pending / paid / failed / cash_on_delivery`)
- Бесплатная доставка от 6000 ₽
- Audit log при ключевых операциях

## Быстрый запуск в PyCharm
1. Откройте папку проекта `zakaz5`.
2. Создайте venv (например через UI PyCharm).
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и при необходимости измените параметры.
5. Примените миграции:
   ```bash
   alembic upgrade head
   ```
6. Заполните демо-данные:
   ```bash
   python seed_demo.py
   ```
7. Запустите приложение:
   ```bash
   python main.py
   ```
8. Откройте `http://127.0.0.1:8000`.
